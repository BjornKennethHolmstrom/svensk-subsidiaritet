# Transition

## The destination isn't the only thing that matters — so is the path

**[Governance Architecture](/arkitektur/)** describes where Sweden could move, and what each architecture gains and loses. But an architecture can be superior in its mature form and still be dangerous to introduce too early.

If we distribute responsibility before we've built better coordination, **coordination can collapse**. If we delegate mandates before accountability chains are clear, **accountability can collapse**. If more actors are meant to participate without better information and deliberation structures, **decision speed can collapse**.

We call this the **transition valley** — a temporary degradation that can occur between two otherwise superior equilibria.

> **A destination can be superior while the path toward it temporarily makes the system worse.**

Transition, then, isn't about arguing that objection away. It's about **engineering the transition** so we never have to enter the weakest part of the valley without having already built what compensates for the loss.

### [Bridge Institutions →](/overgang/broinstitutioner/)

The concrete capabilities — evidence infrastructure, deliberative infrastructure, coordination infrastructure, accountability infrastructure, interoperability and meta-governance — that make the valley shallow or make it disappear altogether.

### [Swedish Reform Path →](/overgang/reformvag/)

How this translates into a concrete, phased reform order for Sweden — with safeguards that ensure authority never spreads faster than the system's ability to coordinate, hold accountability and integrate new knowledge.

## The transition principle

> **Preserve → strengthen → connect → test → delegate → integrate → adapt.**

Not:

> **Decentralize → hope that coordination emerges.**

That's the difference between weak gradualism ("let's change things slowly") and what we call **transition engineering** ("let's change things in dependency order"). Some reforms should happen early even if they produce little visible political change, because they are **enabling infrastructure**. Other reforms should wait even if they're normatively attractive, because the system isn't ready yet.
