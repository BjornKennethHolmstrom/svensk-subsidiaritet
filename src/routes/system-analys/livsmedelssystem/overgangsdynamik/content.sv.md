# Övergångsdynamik

[← Tillbaka till huvudartikeln](..)

**Sammanfattning:** Hur förändringar i livsmedelssystemet kan prövas stegvis: genom många små försök som får misslyckas, en bredd av olika vägar samtidigt, och ett systematiskt lärande om vad som fungerar.

## Små försök som får misslyckas

I komplexa system är det svårt att veta i förväg vad som fungerar. Därför är det klokt att pröva många mindre försök, där ett misslyckande inte hotar helheten, i stället för en stor reform. Det kräver att kommuner, myndigheter och organisationer vågar redovisa även det som inte fungerade, och att utvärderingen planeras från början.

## Flera vägar samtidigt

Förändring kan drivas av olika aktörer parallellt:

- **Kommuner**, genom upphandlingens utformning, markanvändning och planering.
- **Producenter**, genom kooperativ, delade anläggningar och direktförsäljning.
- **Civilsamhället**, genom REKO-ringar, odlingsnätverk och konsumentkooperativ.
- **Staten**, genom beredskap, regler och jordbrukspolitik.

Om en väg stannar av kan de andra fortsätta.

## Från lokalt till nationellt

Lösningar som fungerar lokalt kan spridas till fler orter, och i vissa fall ligga till grund för ändrade regler. Ett exempel är gårdsslakt: efterfrågan fanns länge hos lantbrukare, och när EU:s regler ändrades kunde de första svenska gårdarna godkännas. Forskningen om komplexa system talar om sådana förlopp som att förändringar rör sig mellan olika nivåer i ett system.

## Kriser som tillfällen

Kriser kan skapa ett tillfälle att pröva nya lösningar, men också en frestelse att bara återställa det gamla. Övningar där kommuner, lantbrukare och myndigheter går igenom vad som händer vid till exempel ett avbrott i importen av drivmedel eller gödsel kan visa var sårbarheterna finns, innan en verklig kris inträffar.

## Att inte låsa fast för tidigt

Nationella regler och standarder bör helst bygga på erfarenheter från försök. Tillfälliga undantag och försöksverksamheter kan ges ett slutdatum, som kan förlängas om de fungerar.

## Invändningar

**"Det behövs handlingskraft, inte experiment."** Försök är ett sätt att handla snabbt utan att binda upp sig vid en lösning som kanske inte fungerar.

**"Vem samordnar?"** Gemensamma sätt att utvärdera och dela erfarenheter behövs, till exempel genom länsstyrelser, Jordbruksverket och forskare.
